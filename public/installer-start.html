1

앱 설치 또는 접속

두 가지 방법 중 하나를 고르세요. 화면과 기능은 똑같습니다.

A. 안드로이드 앱 설치 추천

배정이 오면 앱 알림이 바로 울립니다. 앱은 플레이 스토어에 없고, 아래 버튼으로 설치 파일(.apk)을 내려받아 설치합니다.

안드로이드 앱 내려받기 (12MB)
  1. 위 버튼을 누르고, 내려받기가 끝나면 열기를 누릅니다.
    놓쳤다면 알림창이나 내 파일 → 다운로드에서 installer_app.apk를 누르세요.
  2. “출처를 알 수 없는 앱” 안내가 나오면 설정 → 이 출처 허용을 켜고 뒤로 돌아옵니다.
  3. 설치를 누릅니다.
    “Play 프로텍트” 경고가 나오면 세부정보 더보기 → 무시하고 설치를 누르세요. 본사 전용 앱이라 나오는 안내입니다.
  4. 홈 화면의 Aqara 기사 앱을 엽니다.
  5. 알림 허용을 묻는 창이 나오면 반드시 허용을 누르세요.
알림을 거부하면 앱 알림이 오지 않고 문자로만 받게 됩니다. 실수로 거부했다면 휴대폰 설정 → 애플리케이션 → Aqara 기사 → 알림을 켜 주세요.

B. 인터넷(웹)으로 접속

아이폰이거나 앱을 설치하지 않을 경우, 휴대폰 인터넷(크롬·삼성 인터넷·사파리)에서 아래 주소를 엽니다. 배정 안내는 문자로 받습니다.

www.aqaralife-service.kr/installer
홈 화면에 추가해 두면 다음부터 바로 열 수 있습니다.
· 안드로이드: 브라우저 메뉴(⋮) → 홈 화면에 추가
· 아이폰: 공유 버튼(□↑) → 홈 화면에 추가
2

휴대폰 번호로 로그인

비밀번호는 없습니다. 본사에 등록된 휴대폰 번호로 인증번호를 받아 로그인합니다.

  1. 휴대폰 번호 입력 → 인증번호 받기
  2. 문자로 온 6자리 숫자 입력
  3. 확인하고 로그인
화면 예시
기사 로그인
휴대폰 번호
010-1234-5678
인증번호 6자리
123456
확인하고 로그인
번호 다시 입력
인증번호는 5분 동안만 유효합니다. 시간이 지나면 다시 받아 주세요.

처음 로그인하면 사용 안내 4장이 나옵니다. 다음으로 넘기고 시작하기를 누르세요. 안내는 [내 정보] 탭에서 다시 볼 수 있습니다.

3

배정 알림 받기

새 작업이 배정되면 이렇게 안내가 갑니다.

  • 앱을 설치한 경우: 먼저 앱 알림이 옵니다. 알림을 누르면 앱이 열립니다. 5시간 안에 응답하지 않으면 문자로도 한 번 더 안내합니다.
  • 웹으로 쓰는 경우: 문자(카카오 알림톡)로 안내가 갑니다.

문자 속 링크를 누르면 로그인 없이 바로 수락·거절할 수 있습니다.

알림 예시
아카라라이프 설치 기사로 등록하신 기사님께 설치 배정 요청드립니다. 설치 희망일: 9월 20일 지역: 서울 강동구 아래 링크에서 설치 가능 여부를 선택해 주세요. www.aqaralife-service.kr/i/i/… ※ 9월 18일 14:00까지 회신이 없으면 다른 기사님께 자동으로 배정됩니다.

같은 배정은 앱에도 들어옵니다. 문자를 놓쳤다면 앱을 열어 하단 [설치] 탭의 응답 대기 목록을 확인하세요. 탭 아이콘의 빨간 숫자가 지금 처리할 건수입니다. (A/S 배정은 [A/S] 탭에 들어옵니다.)

4

수락 또는 거절

문자 링크 화면이나 앱의 작업 상세(카드를 누르면 열림)에서 일정·주소를 보고 결정합니다. 어느 쪽에서 해도 결과는 같습니다.

  1. 가능하면 수락하기
  2. 어려우면 거절하기 → 사유 선택 → 거절 확정
기한 안에 응답하지 않으면 다른 기사님께 자동으로 넘어갑니다. 못 가는 건은 빨리 거절해 주셔야 고객 일정이 늦어지지 않습니다.
5

6

설치 후 완료 등록

설치를 마치면 작업 상세의 완료 등록을 누르고 아래 항목을 채웁니다.

  1. 연동 등급 선택: 없음 / APP 연동 / 허브 연동
  2. 월패드를 연동했다면 월패드 연동함 체크 (현장 금액은 선택 입력)
  3. 장거리 비용이 있으면 금액 입력 (선택)
  4. 사진 1~4장 첨부: 📷 촬영 또는 🖼 앨범에서 선택
  5. 완료 제출 → 정산 금액 확인 → 제출하기

사진이 없으면 제출할 수 없습니다. APP·허브 연동을 했다면 APP 화면 사진을 꼭 넣어 주세요.

제출하면 작업이 검수 대기로 바뀌고, 본사 승인 후 정산 금액이 확정됩니다. 본사가 반려하면 목록에 빨간 테두리로 사유가 표시되니, 내용을 고쳐 다시 완료 등록해 주세요.

현장에서 통신이 끊겨도 입력한 내용은 휴대폰에 저장됩니다. 통신이 돌아온 뒤 앱의 [설치] 탭을 열면 자동으로 전송되고, 실패하면 화면 위쪽에 사유가 표시됩니다.

자주 막히는 곳

“등록된 기사 번호가 아닙니다”가 나와요
본사에 등록된 번호와 다른 번호입니다. 본사에 번호 확인을 요청해 주세요.
인증번호 문자가 안 와요
30초 이상 기다린 뒤 번호 다시 입력 → 인증번호를 다시 받으세요. 1시간에 5번까지 받을 수 있으며, 넘으면 잠시 후 다시 시도해야 합니다.
배정 목록이 비어 있어요
아직 배정된 작업이 없는 상태입니다. 새 배정이 오면 앱 알림 또는 문자로 알려 드립니다.
